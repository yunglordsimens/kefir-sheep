# kefir-sheep

**flock** — a search engine that slowly sinks.

It starts as an ordinary results page for "how to make kefir at home". Every question you open under *People also ask*, every result, image, video and forum thread you visit takes you a little deeper — from cute sheep to deep web core. At the bottom there is a bag. Shake it.

Live: https://yunglordsimens.github.io/kefir-sheep/

Plain HTML, CSS and JS, no build step. All pictures except the two photos in `assets/` are drawn in canvas at runtime.

Earlier versions live on the `v00`, `v01` and `v02` branches.
